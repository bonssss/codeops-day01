# Module 2 Day 11 Mini Project

## What it does
This is a persistent signup form that validates a user's name and Ethiopian phone number. It displays clear error messages if the input is invalid (e.g. if the name is too short or the phone number doesn't match the required regex), and successfully saves valid entries to the browser's `localStorage` in JSON format. When the page is reloaded, the total number of people who have signed up is restored and displayed on the screen, demonstrating that the data survives a page refresh.

## How to open it
Simply open the `index.html` file in any modern web browser (e.g., by double-clicking it in your file explorer, or using an extension like Live Server in VS Code).
