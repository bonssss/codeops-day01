Exercise 3: Specificity

This paragraph is targeted by element (0,0,1), class (0,1,0), and ID (1,0,0). ID wins!

Explanation:

  • p { color: blue; } - Element selector. Specificity: 0,0,1
  • .spec-class { color: green; } - Class selector. Specificity: 0,1,0
  • #spec-id { color: red; } - ID selector. Specificity: 1,0,0 (Highest, this color wins)
