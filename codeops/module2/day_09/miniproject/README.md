# Addis Market Shopping List

## Description
This is an interactive single-page application (SPA) for managing a shopping list. It allows users to:
- Add items with their name and price (ETB).
- Mark items as "bought" by clicking on them.
- Delete items from the list.
- See a live running total of all items in the list.

This project is built purely with vanilla HTML, CSS, and JavaScript, focusing on DOM manipulation, event handling, and event delegation.

## How to Open
1. Clone or download this repository.
2. Open the project folder on your computer.
3. Double-click the `index.html` file to open it in your default web browser. 
4. Alternatively, if you use VS Code, you can use the **Live Server** extension to serve the file locally.

## Files Included
- `index.html`: The structure of the application.
- `styles.css`: The styling and visual design.
- `app.js`: The JavaScript logic for interactivity.
