# Country Finder Miniproject

A simple, vanilla JavaScript single-page application that allows users to search for a country and view facts about it.

## Features
- Fetches real-time country data using the [REST Countries API](https://restcountries.com/).
- Defaults to showing facts about Ethiopia on the first load.
- Shows a loading indicator while fetching data.
- Handles network errors and invalid searches gracefully with user-friendly error messages.
- Dynamically renders DOM elements using JavaScript's `createElement`.

## How to Run
1. Clone this repository to your local machine.
2. Navigate to the project directory.
3. Open `index.html` in your web browser (no local server or build tools required).

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla, Async/Await, Fetch API)
