# Day 9 Exercises: DSA III (Trees, Graphs & Heaps)

This folder contains exercises for Day 9, focusing on Data Structures and Algorithms including Trees, Binary Search Trees, Graphs, and Heaps.

## Level 1 (Basic)
* **`tree.py`**: Implements a basic `TreeNode` class to construct and visualize a bank hierarchy (Head Office, Branches, Teller, Loan Officer) using recursive indentation.
* **`binary_search_tree.py`**: Creates a Binary Search Tree (BST) structure. Includes functionality to recursively insert numerical values and search for the existence of specific nodes.
* **`graph.py`**: Demonstrates graph basics by creating a dictionary-based adjacency list to track connections and money transfers between various customers.
* **`heap.py`**: Uses Python's built-in `heapq` module to create a priority queue for urgent bank transactions. Implements a max-heap behavior using negative priority values to guarantee that the highest-priority transactions are popped first.
